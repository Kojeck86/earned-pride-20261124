# One Line of Earned Pride

Entry for the make.fun bounty "One Line of Earned Pride": a program that writes one quiet, earned moment of pride to `/output/entry.txt`. A retired bus driver, after two years of night classes, reads his granddaughter a whole bedtime story without once stopping to sound out a word — the effort is inside the line, and the pride lands in the last few words.

Run with `python3 main.py`; it writes a single line of 1–240 characters to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` for local runs). Standard library only, deterministic — every run produces the same line.
